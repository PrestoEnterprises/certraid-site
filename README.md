# CertRaid website

Public help, terms, privacy and account-deletion pages for the CertRaid app (Presto Enterprises LLC), served with GitHub Pages.

Plain HTML and CSS, no build step. Edit a page, commit, push to main, and GitHub Pages republishes in about a minute.

The app links here from `src/constants/legal.ts` (`SITE`). The store listings use the same pages: Help = Support URL, privacy.html = Privacy Policy URL, delete-account.html = Google Play account deletion URL.
